Evaluate an expression

Math.Evaluate parses and evaluates an expression. The same expression tree can be inspected with Math.Parse, rewritten with Math.Simplify and differentiated with Math.Derivative (with respect to x). Expressions are evaluated with x = 2.

High-precision numbers and fractions

Math.Bignumber returns a MathNumber, so arithmetic goes through Math.Add / Math.Multiply and is exact. Math.Fraction returns a typed Fraction; Math.Num / Math.Den expose its parts and Math.Bernoulli computes Bernoulli numbers.
